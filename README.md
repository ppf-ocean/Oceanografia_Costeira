# Oceanografia_Costeira
Disciplina: Oceanografia Costeira - OCE162 (CEM/UFPR)

Neste repositório serão disponibilizados scripts e dados para realização das atividades orientadas (OR) e de Laboratório (LB) da disciplina OCE-162 do curso de Oceanografia da Universidade Federal do Paraná, Centro de Estudos do Mar, Pontal do Sul (UFPR-CEM).
